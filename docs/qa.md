### 리뷰 워크플로로 찾아 고친 것 (독립 리뷰 3개 + 반박 검증)

- 권한을 허용한 뒤에도 실시간 신호가 멈춰 있던 문제 → 허용 후 다시 시작
- 음성 질문 타이머가 화면이 닫힌 뒤 대화상자를 띄워 앱이 죽을 수 있던 문제 → 종료 시 타이머 정리, 질문마다 번호
- 주행 중 가족 모드를 켜고 꺼도 반영되지 않던 문제 → 즉시 반영
- 시연 패널을 끄면 정차 후 질문이 영영 나오지 않던 문제 → 1분 정차 시 자동으로 주행 종료
- 주행 중 시스템 대화상자 → 홈 화면 안 큰 버튼, 주행 중 테마·프로필 변경 잠금 (Car UX Restrictions)
- 낮/밤 전환 때 화면이 다시 만들어져 주행 기록이 사라지던 문제 → `configChanges`
- 설정 화면이 열려 있는 동안 뒤의 홈 화면이 계속 그려지던 문제 → 숨김
- 빌드 폴더를 iCloud가 복사해 dex 병합이 깨지던 문제 → `build.nosync`

리뷰 워크플로(2개 관점 + 반박 검증, 확인된 지적 9개)로 고친 것: 선택 권한(마이크·알림)을 거절하면 권한 요청이 반복되던 문제, 서비스 시작 실패 시 반쯤 만들어진 서비스, 내비로 바꾸거나 설정을 열 때 질문이 사라지던 문제, 새 질문이 앞 질문(정차 후 질문 묶음 포함)을 지우던 문제, "싫어"가 "응"으로 들리던 음성 판정.

## 남은 확인

- **회전 예고가 내비 경로 주행 중 울리는지**: 다음 회전 수신까지는 11.2 오전에 확인. 오후에는 에뮬레이터의 내비 서버 연결이 계속 끊겨(gRPC `TCP connect timeout`, Wi-Fi를 다시 연결해도 같음) 경로를 받지 못함. 방향지시등 예고는 확인됨.
- **"편안한 길"로 경로가 실제로 바뀌는지**: 위와 같은 이유로 경로가 있는 상태에서 확인하지 못함.

QA용 명령:

```bash
adb shell am start -n ai.motioncare.app/.MainActivity --es route_to "37.3947,127.1112,판교역"
python3 -I sim/feed_geo.py ~/Library/Android/sdk/platform-tools/adb sim/scenarios/B_winding_rough.csv 90
```

(`route_to`는 디버그 빌드에서만 동작합니다.)

## 알려진 문제: 에뮬레이터가 꺼짐 (원인 확인, 11.2)

- 로그에 `Failed to find ColorBuffer`가 보이지만 이는 매 부팅 때 나오는 경고입니다. 실제로는 `Wait for emulator ... to shutdown gracefully` → 스냅샷 저장 → 종료 순서로 **바깥에서 종료 요청**을 받고 꺼집니다. 차 안(logcat)에는 종료 기록이 없습니다.
- 원인: 에뮬레이터를 띄운 셸(터미널 탭, 도구의 백그라운드 작업)이 끝나면 그 자식 프로세스인 에뮬레이터도 종료 신호를 받습니다. Virtual Console을 닫아도 똑같이 꺼졌고, `nohup ... &`로 띄우자 계속 켜져 있었습니다.
- 해결: 아래처럼 `nohup`으로 띄우거나, Android Studio › Device Manager › `Pleos_Connect_v2_1` › Cold Boot Now로 켭니다.

```bash
nohup ~/Library/Android/sdk/emulator/emulator -avd Pleos_Connect_v2_1 -no-snapshot-load > /tmp/emu.log 2>&1 &
```

안녕하세요, Pleos 담당자님.

2026 Pleos Connect 차량앱 공모전에 "멀미 케어"를 출품한 팀 CRAVE의 팀원입니다. 개발 중 확인이 필요한 플랫폼 정책이 있어 문의드립니다.

**프로젝트 요약**

- 뒷좌석 동승자(특히 아이)의 멀미를 줄이는 Android Automotive 앱입니다.
- 방향지시등·내비 경로·속도·실내 공조 신호로 흔들림을 계산합니다.
- 회전 전 음성·무드등 예고, 공조 외기 전환·온도 조절, 휴게소 경유지 제안을 차가 직접 합니다.

**에뮬레이터(Pleos Connect v2.1, API 34)에서 확인한 것**

- Vehicle SDK로 공조 22°C·외기 전환, 무드등 깜빡임 예고
- Pleos TTS/STT 음성 안내와 응답, NaviHelper 경유지 요청
- 포그라운드 서비스(location 유형)로 내비를 앞에 둔 채 계속 동작

**문의 사항**

1. **내비 옆 상태 표시**: 내비 화면 위나 옆에 작은 상태 배지(편안·주의·위험)를 띄우고 싶습니다. 홈 왼쪽 아래 MiniApp 영역에 서드파티 앱 위젯을 등록할 수 있는지, 또는 헤드업 알림을 쓸 수 있는지 궁금합니다. 에뮬레이터에서는 `isSystemImportantNotification` 조건 때문에 시스템 앱 알림만 지도 위에 뜨고, 저희 알림은 알림 센터로만 갔습니다.
2. **클러스터(Driving 뷰)**: 계기판에 서드파티 앱의 표시를 올릴 방법이 앞으로라도 있는지 궁금합니다.
3. **시동 시 자동 시작**: 지금은 앱을 한 번 열어야 서비스가 시작됩니다. 시동·부팅 때 포그라운드 서비스를 시작하는 것이 이런 앱에 허용되는지, 권장 방식이 있는지 알고 싶습니다.
4. **내비에 앱 영역 알리기**: NaviHelper의 `getInternalApi().updateOccupiedRegion(Rect)`로 저희 창이 차지한 영역을 알려 내비가 차 위치를 가리지 않게 하려 했는데, 에뮬레이터에서 `SecurityException: This API is only allowed for system apps`로 거절됐습니다(`NAVI_CUSTOM_ETC` 권한을 넣어도 같음). 서드파티 앱이 쓸 수 있는 방법이 있는지, 또는 내비 경로선(경로 좌표)을 받을 수 있는 API가 계획되어 있는지 궁금합니다.
5. **음성 안내 공존**: 내비의 회전 안내와 저희 음성 예고가 겹치지 않도록 권장하는 패턴(오디오 포커스, 안내 타이밍 등)이 있을까요?

저장소는 비공개로 github.com/toowani/motion-care 에 있으며, 요청하시면 접근 권한을 드리겠습니다.

바쁘신 중에 읽어 주셔서 감사합니다. 답변 주시면 공모전 출품작과 이후 정식 탑재 준비에 적극 반영하겠습니다.
